# 五态科学门禁与拒绝条件规约 (Scientific Gates & Rejection Criteria Specification)

> 本文档定义天枢科研体系中的可组合科学门禁、五态判定逻辑与严格拒绝条件。

---

## 1. 五态判定系统 (Five-State Verification Model)
任何科学审计结论严格限制于五种不可混淆的权威状态：
1. **`pass` (通过)**：所有必要且适用的科学条件均具备真实的、可定位验证的硬证据支持。
2. **`fail` (失败)**：检测到违反物理定律、量纲矛盾、统计测试显著性不满足、代码执行非零崩溃或断言与数据相抵触。
3. **`inconclusive` (未决/证据不充分)**：证据链存在断点、样本量不足、未读全文或缺少必要定位。**严禁自动降级或伪装成 pass**。
4. **`not_applicable` (不适用)**：当前工程无对应主张或当前操作不涉及该维度（例如纯推导不强制统计 p 值；无断言的空账本一律为 not_applicable，**绝不报告虚假全绿 pass**）。
5. **`error` (执行异常)**：审计脚本语法错误、超时或环境依赖缺失。

## 2. 门禁注册表与审查职责
| 门禁 ID | 门禁名称 | 审查职责与拒绝条件 |
|---|---|---|
| `provenance-integrity` | 溯源与产出物完整性 | 任何引用的数据、推导或运行收据不存在、哈希校验不符时拒绝。 |
| `literature-grounding` | 文献锚定与真实性 | DOI/arXiv 无法解析、Locator 伪造、引文在原文中无法检索时拒绝。 |
| `data-quality` | 数据质量与转换自洽 | 存在未处理异常缺失值、非法类型或不可逆不可追溯清洗时拒绝。 |
| `statistical-validity` | 统计假定与有效性 | 违反独立性/方差齐性假定、滥用不当检验、未报告效应量或置信区间时拒绝。 |
| `dimensional-consistency` | 物理量纲齐次性 | 任何方程式左右两端或加和项之间 SI 物理量纲不齐次立即拒绝。 |
| `symbolic-physical` | 符号代数与边界极限 | 极限退化结果违反已知物理极值或能量守恒不变量时拒绝。 |
| `benchmark-validity` | 基准评测公平性 | 单变量消融未隔离干扰因素、基线与对比模型计算预算不一致时拒绝。 |
| `reproducibility` | 运行复现与确定性 | 相同随机种子与配置下无法复现产出物、缺少环境指纹时拒绝。 |
| `figure-traceability` | 图表溯源与语义标注 | 坐标轴缺失物理单位、误差棒未说明统计含义 (SD vs 95% CI) 时拒绝。 |

## 3. 严格聚合规则 (Aggregation Rules)
- **空项目保护**：空账本、无 claim 且无 targetIds 时，验证状态必然是 `not_applicable`，坚决避免给空项目发“全部通过”假报告。
- **一票否决**：任何门禁产出 `fail` 或 `error`，整体项目验证状态必然判定为 `fail`。
- **真实全量通过**：只有在至少存在 1 个适用门禁为 `pass`，且 0 fail、0 error、0 inconclusive 时，整体状态才允许判定为 `pass`。
